# 🧹 Dataset-1 – Cleaned & Normalized Data

## 📌 Contents Overview

This directory contains the cleaned, transformed, and normalized datasets for **Dataset-1**, prepared for high-performance ingestion into the Power BI semantic model.

---

## ⚙️ Data Preparation Protocol

- Enforced consistent column headers across all tables.
- Removed null rows and trailing whitespace in string dimensions.

- Split compound fields into discrete dimensional attributes.
