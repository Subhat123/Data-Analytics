# 📊 Power BI – Dataset 2 Analytics Track

## 📌 Project Overview

This directory houses the second Power BI business intelligence project track for **Dataset-2**. It provides an end-to-end framework for data ingestion, cleaning, dimensional modeling, and report visualization.

---

## 🗂️ Pipeline Structure

```text
Dataset-2/
├── Analysis/       # Metric blueprints, business objectives, and modeling schemas
├── Cleaned Data/   # Sanitized data tables ready for Power BI consumption
├── Dashboard/      # Interactive Power BI report files (.pbix) and dashboards
└── Raw Data/       # Source input files
```

---

## 🎯 Analytical Stages

1. **Source Acquisition:** Storage of incoming data tables in `Raw Data/`.
2. **Data Wrangling:** Power Query ETL cleaning, schema reshaping, and null handling in `Cleaned Data/`.
3. **Analytical Scoping:** Defining KPIs, measures, and data dictionaries in `Analysis/`.
4. **Visual Delivery:** Dashboard layout, drill-through, and storytelling in `Dashboard/`.
