## 📐 Standard Folder Architecture

Each dataset project track contains four synchronized stages:
1. `Raw Data/`: Preserves raw input records.
2. `Cleaned Data/`: Processed, cleansed tables ready for semantic modeling.
3. `Analysis/`: Business questions, KPI formulas, and modeling documentation.
4. `Dashboard/`: Power BI report files (`.pbix`) and exported visual assets.
