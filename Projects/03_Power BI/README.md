---

## 🎯 Objectives & Methodology

The Power BI curriculum builds professional competence in:
- **Power Query ETL:** Extracting, unpivoting, merging, and transforming disparate data sources into normalized star-schema models.
- **Data Modeling:** Establishing one-to-many relationships, enforcing referential integrity, and configuring dimension/fact table hierarchies.
- **DAX (Data Analysis Expressions):** Authoring calculated columns, explicit measures, time-intelligence functions (`TOTALYTD`, `SAMEPERIODLASTYEAR`), and iterator functions (`SUMX`, `AVERAGEX`).
- **Data Visualization & UX:** Designing executive report canvases, incorporating bookmarks, drill-through paths, dynamic tooltips, and custom theme palettes.

---

## 📁 Pipeline Organization

Both dataset workspaces (`Dataset-1` and `Dataset-2`) are structured according to standard data project lifecycles:
- **`Raw Data/`**: Source data extracts.
- **`Cleaned Data/`**: Transformed and validated datasets ready for model ingestion.
- **`Analysis/`**: Requirement specifications, DAX measure blueprints, and data dictionaries.
- **`Dashboard/`**: Finished Power BI reports (`.pbix`), published links, and visual export assets.
