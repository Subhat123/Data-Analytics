# 🐍 04_Python – Programming, Software Engineering & Data Science

This module contains practical Python programming labs, algorithmic foundations, object-oriented software engineering projects, data manipulation notebooks, and console applications for data analytics.

---

## 🗂️ Module Architecture

```text
04_Python/
├── Day_1/                # Python syntax, variables, operators, and type casting
├── Day_2/                # Interactive menu-driven console portals and flow control
├── Exception Handling/   # Defensive programming, try/except, custom raise ValueError
├── File handling/        # Text, CSV (DictReader/Writer), and JSON I/O operations
├── file.py/              # Interactive Jupyter notebooks for file I/O and Pandas
│   └── Pandas.py/        # Pandas DataFrame practice and BeautifulSoup web scraping
├── Foundations/          # Core conditional logic, sets, and dictionary basics
├── ML/                   # Machine learning practice notebooks (pandas, data preparation)
├── Nova_Console_app/     # Enterprise 870+ line console-based Student Information System
├── oops/                 # Object-Oriented Programming (Classes, Encapsulation, Inheritance, ABC)
└── Pr_learning/          # Deep-dive syntax practice
    ├── Dict_methods/     # Dictionary manipulations, key/value iteration, unpacking
    └── Nested_if,match_case/ # Multi-branching logic, elif ladders, and match-case patterns
```

## 🚀 Key Modules & Project Highlights

| Module | Core Topics | Key Deliverables |
| :--- | :--- | :--- |
| **[Nova Console App](./Nova_Console_app/)** | Real-world CLI application design, defensive input validation, CRUD operations, student reporting | `main.py` (870+ lines of robust, production-style Python) |

| **[File Handling](./File%20handling/)** | Multi-format data storage: Plain text (`r/w/a/x`), structured CSV (`DictReader/Writer`), hierarchical JSON (`load/dumps`) | `csv_handling.py`, `json_program.py`, `file_h.py` |
| **[Pandas & Web Scraping](./file.py/Pandas.py/)** | DataFrames, series indexing, filtering, HTTP requests, BeautifulSoup parsing | `panda practice.ipynb`, `web.py` (scraping books catalog) |
| **[Exception Handling](./Exception%20Handling/)** | Error interception, graceful degradation, business rule validation loops | `Exception.py`, `final.py` |

## 🛠️ Execution & Environment

Python version: **Python 3.14** (or compatible 3.10+).

To run any script:
```bash
python path/to/script.py
```
To run notebooks:
```bash
jupyter notebook
```
