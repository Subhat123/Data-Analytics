# 🔰 Day 1 – Python Installation, Variables & Operators

## 📌 Overview

This directory contains the foundational programming lab exercises for Day 1 of the Python curriculum. The tasks focus on verifying the Python environment, managing user input, inspecting data types, performing arithmetic and logical operations, and applying explicit type casting.

---

## 🗂️ Task Scripts Catalog

| Script | Title / Topic | Code Highlights & Logic |
| :--- | :--- | :--- |
| **`task_01.py`** | Environment Verification | Imports `sys` and prints `sys.version` to verify that Python is correctly installed and executing. |
| **`task_02.py`** | Dynamic User Input | Captures student profile fields (`name`, `id`, `department`, `age`, `semester`) via `input()` and builds student records with list-of-dictionaries structures. |
| **`task_03.py`** | Data Type Inspection | Collects diverse inputs (`int`, `float`, `str`) and inspects memory types dynamically using `type()`. |
| **`task_04.py`** | Arithmetic & Comparison Operators | Computes subject sums, averages, fee balances, comparison checks (`>`), logical conditions (`and`), and compound increments (`+=`). |
| **`task_05.py`** | Explicit Type Casting | Converts string representations of numbers to `int` and `float`, inspecting type changes before and after casting. |
| **`task_06.py`** | Nova University Student Profile | Capstone Day 1 exercise integrating input parsing, mark totals, remaining marks, pass/fail evaluation, eligibility validation, and formatted profile printing. |

---

## 🚀 How to Run

Execute each script via terminal:
```bash
python task_01.py
python task_06.py
```
