# 📚 Practice Learning Labs (Pr_learning)

## 📌 Overview

This directory contains targeted practice modules focusing on essential Python data structure methods and advanced conditional flow control patterns.

---

## 🗂️ Submodules

| Subfolder | Topic | Scope |
| :--- | :--- | :--- |
| **[`Dict_methods/`](./Dict_methods/)** | Python Dictionaries | In-depth exploration of dictionary keys, values, key-value pairs (`items()`), lookups (`get()`), updates, and deletions (`pop()`, `del`). |
| **[`Nested_if,match_case/`](./Nested_if,match_case/)** | Multi-Branch Flow Control | Deep dive into nested conditional structures, grade ladders (`elif`), and Python 3.10+ pattern matching with `match-case`. |
