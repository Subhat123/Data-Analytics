# 🧱 Python Foundations – Logic, Sets & Dictionaries

## 📌 Overview

This directory contains introductory exercises focusing on core conditional evaluation and Python's built-in collection types (sets and dictionaries).

---

## 🗂️ Script Catalog

| Script | Concepts Demonstrated | Key Operations |
| :--- | :--- | :--- |
| **`conditions.py`** | Multi-Branch Logic | Evaluates numeric scores against multi-condition thresholds (`if-elif-else`) to output performance ratings ("Excellent", "Good", "Pass", "Fail"). |
| **`set practice.py`** | Set Operations & Mutation | Covers fundamental set methods: `add()`, `update()`, `pop()`, `discard()`, `remove()`, and initial dictionary definitions using curly braces `{}`. |
| **`demo.py`** | Syntax Scratchpad | Introductory code experiments and syntax trials for variables and basic operations. |

---

## 🚀 Execution

```bash
python conditions.py
python "set practice.py"
```
