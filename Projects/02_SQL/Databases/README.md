## 🗂️ Typical Database Structure

Each database project folder includes:
- `Cleaned/`: Modular, numbered SQL scripts (`01` through `05`/`07`) splitting the database lifecycle into distinct steps (DDL, validation, business analytics, window functions, KPIs).
- `Queries/`: Full consolidated monolithic SQL scripts.
- `Document/`: Comprehensive PDF project reports showing query outputs, entity-relationship diagrams, and data dictionaries.
- `Dashboard/`: Visual exports or reporting representations.
