# 📊 Medicare – Hospital Operational Dashboards

## 📌 Contents Overview

This directory is designated for visual reporting artifacts, interactive dashboard exports, and KPI summaries connected to the Medicare hospital database.

---

## 🎯 Target Operational Metrics

- **Bed Occupancy & Admissions:** Inpatient admission duration, department capacity, and discharge velocity.
- **Physician Workload:** Doctor appointment volume, consultation throughput, and specialization distribution.
- **Financial Flow:** Inpatient treatment costs, outpatient billing, and pharmacy revenue collection efficiency.
