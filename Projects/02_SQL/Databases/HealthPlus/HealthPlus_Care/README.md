# HealthPlus Care SQL Project

Run the SQL files in numerical order in MySQL Workbench.

- `01_Database_and_Tables.sql` — creates the database and tables.
- `02_Data_Quality_Validation.sql` — row counts, duplicate/null checks, date and business-rule checks, billing validation, foreign-key validation, outlier analysis, and profiling.
- `03_Business_Analysis.sql` — clinic, specialist, telemedicine, chronic care, package, corporate, prescription, lab, claims, revenue, and feedback analysis.
- `04_Window_Functions.sql` — ROW_NUMBER, RANK, LAG, and LEAD.
- `05_Final_KPI_Queries.sql` — final KPI queries.
