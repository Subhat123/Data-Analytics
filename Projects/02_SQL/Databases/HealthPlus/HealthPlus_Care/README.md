# 🏥 HealthPlus Care – Core SQL Package

## 📌 Contents Overview

This directory contains the core standalone distribution of the HealthPlus Care SQL scripts, mirrored for independent deployment and testing.

---

## 🗂️ Script Catalog

| Script | Purpose |
| :--- | :--- |
| **`01_Database_and_Tables.sql`** | Database schema definition, table creation, and primary/foreign key constraints. |
| **`02_Data_Quality_Validation.sql`** | Automated data quality verification queries and referential integrity checks. |
| **`03_Business_Analysis.sql`** | Complex analytical queries solving key healthcare operational questions. |
| **`04_Window_Functions.sql`** | SQL analytical window functions (`RANK()`, `ROW_NUMBER()`, `LAG()`, `LEAD()`). |
| **`05_Final_KPI_Queries.sql`** | High-level summary queries calculating operational and financial KPIs. |

---

## 💡 Usage

Open the scripts in MySQL Workbench and execute them against your target MySQL server instance.
