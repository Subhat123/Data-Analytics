## 🖥️ Dashboard Features

- **KPI Cards:** Overview of Net Sales, Total Orders, Units Sold, and Average Discount %.
- **Performance Breakdown:** Visual distribution across Clothing, Footwear, and Accessories.
- **Geographic & Channel Analytics:** Comparative charts showing sales performance across territories and ordering channels.
- **Dynamic Slicers:** Interactive filters enabling drill-down analysis by category, quarter, and region.
