## ⚙️ Transformation Highlights

- **Data Standardization:** Reconciled inconsistent category naming, standardized country/state abbreviations, and validated date types.
- **KPI Metrics:** Formatted total sales revenue, total units sold, average order value (AOV), total discount expense, and net revenue.
- **Dynamic Pivot Tables:** Summarized sales by category, channel, and regional performance.
- **Interactive Controls:** Integrated Excel Slicers for rapid multi-dimensional filtering.
