# 🛍️ TrendKart — Sales Performance Dashboard

An interactive Microsoft Excel dashboard for analyzing retail sales, order volume, product quantities, profitability, payment methods, and sales channel performance.

## 📌 Project Overview

TrendKart is an Excel-based data analytics project that presents retail performance through KPI cards, charts, and interactive slicers. The dashboard brings key sales metrics together in one view, making it easier to compare performance across months, sales channels, payment methods, and order types.

## 🎯 Business Problem and Objectives

Retail businesses need a clear view of sales and profitability to understand customer purchasing patterns and monitor business performance.

The objectives of this project are to:

- Summarize order volume, quantity, sales, and profit.
- Analyze monthly sales trends.
- Compare weekday and weekend sales.
- Explore revenue distribution across payment methods.
- Compare sales performance by channel.
- Enable interactive analysis using dashboard filters.
