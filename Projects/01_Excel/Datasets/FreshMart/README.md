# 🛒 FreshMart — Supermarket Sales & Business Performance Analytics

An interactive Microsoft Excel dashboard project designed to analyze supermarket sales, profitability, product performance, and business trends through data-driven reporting.

## 📌 Project Overview

FreshMart is a retail data analytics project that transforms supermarket data into meaningful business insights using Microsoft Excel. It combines sales transactions with customer, product, store, employee, and supplier information to support business performance analysis.

## 🎯 Business Problem and Objectives

Retail businesses need reliable sales reports to understand revenue trends, identify profitable products, and evaluate different sales channels.

The objectives of this project are to:

- Organize retail data for effective analysis.
- Prepare and validate datasets for reporting.
- Monitor sales, quantity, profit, and profit margin.
- Analyze monthly sales trends and category performance.
- Compare sales channels and payment methods.
- Present business metrics through an interactive dashboard.

The sales transactions cover March 2025 to March 2026, according to the project documentation.

## 🧹 Data Cleaning and Preparation

The documented workflow includes:

- Reviewing source spreadsheets and data structures.
- Integrating related data using Excel lookup functions.
- Using `XLOOKUP` and formulas to support data preparation.
- Validating sales and profit calculations.
- Preparing data for PivotTables, charts, and dashboard reporting.

## 🛠️ Tools Used

- **Microsoft Excel**
- `XLOOKUP` and Excel formulas
- PivotTables and PivotCharts
- KPI calculations
- Interactive slicers
- Data cleaning and visualization

## 📊 Dashboard Features and Analysis

- **Monthly Sales Trend** — explores changes in sales over time.
- **Category-wise Sales** — compares sales across product categories.
- **Sales Channel Analysis** — examines revenue across sales channels.
- **Payment Mode Analysis** — compares payment preferences.
- **Product Profitability** — supports product-level profit comparisons.
- **Interactive Filters** — enables filtering by region, payment mode, sales channel, and category.

## ▶️ How to Use the Project

1. Download or clone the repository.
2. Open the `FreshMart` project folder.
3. Download the Excel workbook from `Cleaned Data/`.
4. Open the workbook in Microsoft Excel.
5. Explore the dashboard, KPIs, charts, and available slicers.
6. Refer to `Raw Data/` for source spreadsheets and `Analysis/` for the Business Requirements Document.
