# 📄 FreshMart – Business Analysis & Requirements

## 📌 Contents Overview

This directory houses the foundational business documentation that guides the analytical modeling and dashboard design for the FreshMart project.

---

## 🗂️ Files

| File | Description | Purpose |
| :--- | :--- | :--- |
| **`FreshMart_BRD.docx`** | Business Requirements Document (BRD) | Defines business objectives, stakeholder needs, metric definitions, target KPIs, and project milestones. |

---

## 🎯 Analytical Scope

- **Problem Statement:** Identification of revenue leaks, underperforming store formats, and inventory turnover gaps.
- **Metric Definitions:** Standardizing core formulas including Average Order Value (AOV), Sales per Employee, Gross Margin %, and Customer Retention Rate.
- **Reporting Hierarchy:** Outlines required views for regional directors, category managers, and store supervisors.
