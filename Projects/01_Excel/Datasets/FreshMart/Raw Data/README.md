# 📦 FreshMart – Raw Datasets

## 📌 Contents Overview

This directory stores the unedited source datasets for the FreshMart project across all operational dimensions.

---

## 🗂️ Data Files

| File Name | Size | Scope & Description |
| :--- | :--- | :--- |
| **`FreshMart_Customers.xlsx`** | ~67 KB | Customer profiles, including customer IDs, demographics, location, and registration dates. |
| **`FreshMart_Employess.xlsx`** | ~29 KB | Employee records, store assignments, roles, compensation tiers, and hire dates. |
| **`FreshMart_Products.xlsx`** | ~20 KB | Product catalog listing item IDs, product names, categories, standard cost, and retail prices. |
| **`FreshMart_Sales_Transactions.xlsx`** | ~314 KB | Point-of-Sale (POS) transaction logs with invoice IDs, timestamps, quantities, and line totals. |
| **`FreshMart_Stores.xlsx`** | ~22 KB | Physical store master table including store codes, formats, square footage, and regional tags. |
| **`FreshMart_Suppliers.xlsx`** | ~16 KB | Supplier and vendor metadata, including company names, lead times, and product categories. |
| **`FreshMart_Enterprise_Dataset.xlsx`** | ~376 KB | Consolidated enterprise dataset joining core relational dimensions for cross-functional modeling. |

---

## ⚠️ Data Usage Notice

All files in this directory are preserved in their original format to ensure analytical reproducibility and allow the transformation pipeline to be rerun from source data at any time.
