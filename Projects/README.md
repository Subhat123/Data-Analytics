# 📁 Analytics & Engineering Projects

This directory contains all domain-specific project suites, organized progressively from foundational data wrangling to enterprise database querying, visualization, and programming.

---

## 🗂️ Project Directory Structure

```text
Projects/
├── 01_Excel/          # Business requirements, spreadsheet analytics, executive KPI dashboards
├── 02_SQL/            # Healthcare databases, data quality assurance, analytical SQL scripts
├── 03_Power BI/       # Interactive dashboards and data visualization datasets
├── 04_Python/         # Programming labs, algorithmic foundations, OOP, and software applications
├── 05_AI/             # Artificial intelligence models and workflows
└── 06_Statistics/     # Statistical evaluation assignments, questions, and solutions
```

---

## 🔍 Module Summaries

### 1. [01_Excel](./01_Excel/)
Contains end-to-end spreadsheet analysis projects featuring real-world retail datasets:
- **FreshMart:** Multi-store supermarket retail operations, customer profiling, and sales dashboard.
- **TrendKart:** Multi-category fashion retail performance and executive dashboard.

### 2. [02_SQL](./02_SQL/)
Contains production-grade relational database setups and analytical query scripts:
- **HealthPlus:** 17-table healthcare management system covering clinics, telemedicine, prescriptions, claims, and KPIs.
- **Medicare:** Hospital operations system covering admissions, treatment costs, doctor workload, and window functions.

### 3. [03_Power BI](./03_Power%20BI/)
Dedicated to Business Intelligence development:
- Houses structured data pipelines with clean separation between Raw Data, Cleaned Data, Analysis, and Dashboards across multiple dataset tracks.

### 4. [04_Python](./04_Python/)
A progression of software engineering and data science implementations:
- Daily curriculum tasks (`Day_1`, `Day_2`)
- Core programming concepts (`Foundations`, `Exception Handling`, `File handling`, `oops`, `Pr_learning`)
- Advanced modules: `file.py` (Pandas and Web Scraping), `ML` (Jupyter notebooks), and the enterprise-grade **Nova Console App**.

### 5. [05_AI](./05_AI/)
Workspace reserved for machine learning models, neural network implementations, and generative AI integrations.

### 6. [06_Statistics](./06_Statistics/)
Curriculum and practical problem sets addressing statistical reasoning, descriptive measures, hypothesis tests, and probability modeling.
