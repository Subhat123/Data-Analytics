# 📊 Data Analytics Portfolio & Knowledge Base

Welcome to the **Data Analytics Repository**. This repository serves as a centralized, structured portfolio documenting comprehensive data analysis, business intelligence, database engineering, Python programming, machine learning, and statistical analysis projects.

---

## 🗂️ Repository Architecture

The repository is modularly organized into distinct learning and project tracks under the [`Projects`](./Projects/) directory:

```text
Data Analystics/
└── Projects/
    ├── 01_Excel/          # Business intelligence spreadsheets, BRD analysis, KPI dashboards
    ├── 02_SQL/            # Relational database design, ETL validation, window functions, analytics
    ├── 03_Power BI/       # Interactive dashboards, semantic models, reports (Datasets 1 & 2)
    ├── 04_Python/         # Foundations, OOP, file I/O, scraping, pandas, Nova Console App, ML
    ├── 05_AI/             # Artificial Intelligence and Deep Learning explorations
    └── 06_Statistics/     # Statistical modeling, hypothesis testing, analytical documentation
```
